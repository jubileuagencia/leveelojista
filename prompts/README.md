# Prompts — Agencia Jubileu

Biblioteca de prompts otimizados para producao de conteudo e estrategia com IA.

## Estrutura

### `/content/`
Prompts para criacao de conteudo.
- `copy-instagram-post.md` — Gerar legendas para posts
- `roteiro-reels.md` — Gerar roteiros de videos curtos
- `legendas-stories.md` — Gerar textos para stories
- `ideias-conteudo.md` — Brainstorm de ideias por pilar

### `/strategy/`
Prompts para planejamento estrategico.
- `analise-concorrente.md` — Analisar concorrencia
- `persona-mapping.md` — Criar/refinar personas
- `planejamento-campanha.md` — Planejar campanhas

### `/automation/`
Prompts para configuracao de automacoes.
- `manychat-flows.md` — Gerar fluxos de ManyChat
- `substack-newsletter.md` — Gerar newsletters

## Como usar

1. Abra o prompt desejado
2. Substitua os `{placeholders}` pelas informacoes do cliente
3. Cole no ChatGPT, Claude ou ferramenta de IA
4. Revise e ajuste o resultado antes de usar

## Regras

- Sempre revise o output da IA antes de publicar
- Adapte o tom de voz conforme o brand-dna do cliente
- Nunca publique conteudo 100% gerado por IA sem revisao humana
