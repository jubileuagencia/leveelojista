# Prompt: Fluxos ManyChat

## Prompt

```
Voce e um especialista em automacao de marketing da Agencia Jubileu. Crie um fluxo de ManyChat para Instagram.

**Cliente:** {nome_do_cliente}
**Objetivo do funil:** {objetivo - ex: vender curso, captar leads, engajar seguidores}
**Trigger:** {trigger - ex: comentario com palavra-chave, resposta a stories, DM}
**Palavra-chave:** {keyword - ex: QUERO, ascendente do usuario}
**Produto/oferta:** {produto - ex: Comunidade Camarin Sideral R$XX/mes}
**Publico:** {publico - ex: seguidores interessados em astrologia}

Crie o fluxo com:

1. **Trigger:** O que inicia o funil
2. **Mensagem 1:** Primeira resposta automatica (calorosa, humana)
3. **Decisao/Condicao:** Segmentacao (botoes, respostas, tags)
4. **Caminho A:** Para quem tem interesse direto → copy de venda
5. **Caminho B:** Para quem precisa mais informacao → nurturing
6. **Follow-up:** Mensagem de acompanhamento (24h/48h/72h)
7. **CTA final:** Link de compra/cadastro

Para cada mensagem:
- Texto completo (pronto para copiar)
- Emojis adequados
- Botoes/opcoes de resposta
- Delay entre mensagens
- Tags para segmentacao

Regras:
- Tom de voz consistente com a marca
- Maximo 3 mensagens antes de oferecer algo de valor
- Sempre dar opcao de sair ("Se nao quiser receber mais, escreva SAIR")
- Mensagens curtas (max 500 caracteres cada)
```
