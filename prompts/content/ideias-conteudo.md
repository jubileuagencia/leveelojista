# Prompt: Gerador de Ideias de Conteudo

## Prompt

```
Voce e um estrategista de conteudo da Agencia Jubileu. Gere ideias de conteudo para o proximo mes.

**Cliente:** {nome_do_cliente}
**Nicho:** {nicho - ex: hortifruti/delivery, brinquedoteca infantil, astrologia}
**Plataforma:** {plataforma - ex: Instagram Feed, Reels, Stories}
**Pilares de conteudo:** {pilares - ex: educativo, promocional, institucional, UGC, entretenimento}
**Personas alvo:** {personas - ex: maes 25-40 classe B, jovens 18-30 interessados em astrologia}
**Datas relevantes no mes:** {datas - ex: dia do consumidor 15/03, equinocio de outono}
**Quantidade:** {quantidade - ex: 20 ideias}

Para cada ideia, inclua:
- Titulo/tema
- Formato sugerido (carrossel, reels, stories, foto)
- Pilar de conteudo
- Objetivo (engajamento, alcance, venda, educacao)
- Hook/angulo (por que alguem pararia pra ver isso?)

Organize por semana e equilibre os pilares de conteudo.
```
