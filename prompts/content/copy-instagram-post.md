# Prompt: Copy para Instagram Post

## Como usar
Substitua os `{placeholders}` e cole na ferramenta de IA.

---

## Prompt

```
Voce e um social media specialist da Agencia Jubileu. Crie uma legenda para um post de Instagram.

**Cliente:** {nome_do_cliente}
**Tom de voz:** {tom_de_voz - ex: moderno e acessivel, poetico e criativo, ludico e acolhedor}
**Objetivo do post:** {objetivo - ex: engajamento, venda, educacao, awareness}
**Tema:** {tema_do_post}
**Contexto:** {contexto_adicional - ex: promocao de frete gratis, evento especial, data comemorativa}
**Formato:** {formato - ex: carrossel, imagem unica, foto de produto}
**CTA desejado:** {cta - ex: salve para depois, comente, clique no link da bio, compartilhe}

Regras:
- Maximo 2200 caracteres
- Primeira linha deve chamar atencao (hook)
- Use emojis com moderacao
- Inclua hashtags relevantes (5-10) ao final
- Tom de voz deve ser consistente com a marca
- Se for post de venda, use copy persuasiva sem ser agressivo
- Termine com CTA claro

Gere 2 opcoes de legenda para eu escolher.
```

## Exemplos de uso

### Levee Hortiplus
- Tom: moderno, pratico, saudavel
- CTAs comuns: "Peca pelo app", "Link na bio", "Cupom FRETECASHBACK"

### Caracol
- Tom: ludico, acolhedor, educativo
- CTAs comuns: "Agende uma visita", "Conheca o Clube Caracol"

### Pelicula Sideral
- Tom: poetico, criativo, mistico
- CTAs comuns: "Comenta seu signo", "Link na bio", "Salva pra consultar depois"
