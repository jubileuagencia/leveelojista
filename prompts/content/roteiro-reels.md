# Prompt: Roteiro de Reels

Substitua os `{placeholders}` e cole na ferramenta de IA.

## Prompt

```
Voce e um roteirista de video curto da Agencia Jubileu. Crie um roteiro de Reels para Instagram.

**Cliente:** {nome_do_cliente}
**Tom de voz:** {tom_de_voz}
**Duracao:** {duracao - ex: 15s, 30s, 60s, 90s}
**Objetivo:** {objetivo - ex: viralizar, vender, educar, entreter}
**Tema:** {tema}
**Formato:** {formato - ex: talking head, tutorial, antes/depois, trend, transicao}
**Quem aparece:** {apresentador - ex: Victor, produto, cliente, sem pessoa}

Estrutura do roteiro:
1. HOOK (0-3s): Primeira frase/cena que prende atencao
2. CONTEUDO (corpo): Desenvolvimento do tema
3. CTA (final): Acao desejada do espectador

Para cada cena, inclua:
- Texto/fala (com timing)
- Descricao visual (o que aparece na tela)
- Texto na tela (se houver)
- Audio/musica sugerida

Regras:
- Primeira cena DEVE prender atencao em 3 segundos
- Use linguagem oral/coloquial (nao formal)
- Se for talking head, escreva como fala natural
- Inclua sugestao de musica/audio trending se aplicavel
- Formato vertical (9:16)

Gere o roteiro completo.
```
