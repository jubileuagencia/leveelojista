## Descricao

Implementar o modulo de gestao de categorias no painel administrativo. O admin precisa criar, editar, excluir e reordenar categorias. Cada categoria pode ter um icone e uma cor associada. As categorias sao usadas no catalogo do lado cliente para filtrar produtos.

### Schema da Categoria (referencia `database.ts`)
```typescript
interface Category {
  id: string
  name: string
  icon: string | null    // Nome do icone (ex: 'apple', 'beef', 'fish')
  color: string | null   // Cor hex (ex: '#10b981')
  created_at: string
}
```

### Funcionalidades
1. **Listagem** - Lista/cards de todas as categorias com icone, cor e contagem de produtos vinculados
2. **Criar Categoria** - Modal com campos: nome, icone (selector), cor (color picker)
3. **Editar Categoria** - Mesmo modal pre-populado
4. **Excluir Categoria** - Com validacao de produtos vinculados
5. **Reordenacao** - Drag-and-drop ou botoes up/down para ordenar exibicao
6. **Vinculacao** - Exibir quantos produtos estao vinculados a cada categoria

## Notas Tecnicas

- **Contagem de Produtos**: Para exibir quantos produtos pertencem a cada categoria, fazer query com subselect ou join.
- **Reordenacao**: Se nao houver campo `sort_order` na tabela, adicionar `sort_order INTEGER DEFAULT 0` na tabela `categories`.
- **Exclusao Segura**: Ao excluir categoria, fazer `UPDATE products SET category_id = NULL WHERE category_id = :id` antes de `DELETE FROM categories WHERE id = :id`. Ideal fazer isso numa transaction ou RPC.
- **Nomes Duplicados**: Verificar unicidade antes de criar/editar.
- **Icones**: Subset sugerido: apple, beef, fish, milk, wheat, carrot, egg, coffee, wine, package, leaf, heart.
- **Cor**: Armazenar como hex string. ColorPicker com palette predefinida + input manual.
- **Drag-and-Drop**: Para MVP, botoes up/down sao suficientes e evitam dependencia externa.
