### Known ClickUp API Limitations

These were discovered during initial setup and affect remaining tasks:

1. **PUT /space does NOT update statuses** — Statuses can only be set during space creation (POST) or via UI. The 6-stage workflow defined (Backlog → To Do → In Progress → Review → Approved → Done) was NOT applied.
2. **Archiving spaces via API doesn't work** — Returns 200 but `archived: false`. Default space must be archived via UI.
3. **Custom fields are list-level, not workspace-level** — Must be created per-list or via templates.
4. **Rate limiting** — ~200ms between requests is safe for batch operations.
