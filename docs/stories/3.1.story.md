## Descricao

Atualmente os 4 workflows do Jubileu OS estão hardcoded em `src/lib/workflows/config.ts`. Isso impede que a equipe crie novos workflows ou adapte os existentes sem deploy.

Esta story migra as definições de workflow para o banco de dados (Supabase) e cria o CRUD completo via API + UI.

### Schema

```sql
CREATE TABLE workflow_definitions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  description TEXT,
  icon TEXT DEFAULT '📋',
  category TEXT NOT NULL CHECK (category IN ('content', 'client', 'development', 'operations', 'custom')),
  steps JSONB NOT NULL DEFAULT '[]',
  is_template BOOLEAN DEFAULT false,
  is_active BOOLEAN DEFAULT true,
  created_by UUID REFERENCES auth.users(id),
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- RLS: admin e member podem CRUD, client sem acesso
-- Trigger: auto-update updated_at
-- Seed: migrar os 4 workflows existentes do config.ts
```

### Step Definition (JSONB schema)

```typescript
interface WorkflowStepDef {
  id: string
  title: string
  description: string
  type: 'manual' | 'automated' | 'approval' | 'agent'
  assignee?: string
  estimatedMinutes?: number
  dependsOn?: string[]
  config?: Record<string, unknown>
}
```

### Funcionalidades

1. **Migration SQL** — Criar tabela `workflow_definitions` com seed dos 4 workflows existentes
2. **API CRUD** — `GET/POST /api/workflows` + `GET/PUT/DELETE /api/workflows/[id]`
3. **Hook** — `useWorkflows()` com React Query (list, create, update, delete)
4. **Workflow Builder UI** — Formulário para criar/editar workflow com steps dinâmicos
5. **Duplicar Workflow** — Botão que clona um workflow existente como novo
6. **Página de listagem atualizada** — Ler do banco em vez do `config.ts`
7. **Backward compatibility** — `getWorkflowById()` busca do banco, fallback para config

### Impacto nos arquivos existentes

- `src/lib/workflows/config.ts` → manter como fallback, marcar como deprecated
- `src/app/(dashboard)/workflows/page.tsx` → usar hook do banco
- `src/app/(dashboard)/workflows/[workflowId]/page.tsx` → buscar definição do banco
- `src/hooks/use-workflow-executions.ts` → manter (executions não muda)
