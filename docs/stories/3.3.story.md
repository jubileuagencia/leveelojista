## Descricao

Atualmente não há forma de ver execuções passadas nem métricas. O usuário só vê execuções ativas. Esta story adiciona histórico navegável e dashboard de métricas por workflow.

### Funcionalidades

1. **Aba "Histórico"** na página de workflow — lista todas as execuções (running, completed, cancelled)
2. **Execution Detail View** — ver execução passada com timeline completa de steps
3. **Métricas por workflow** — cycle time médio, taxa de conclusão, steps que mais atrasam
4. **Filtros** — por status, período, membro da equipe
5. **Comparação** — estimado vs real por step

### Métricas Calculadas

```typescript
interface WorkflowMetrics {
  totalExecutions: number
  completedExecutions: number
  cancelledExecutions: number
  avgCycleTimeMinutes: number        // média de duração total
  avgStepDurations: Record<string, number>  // média por step
  completionRate: number             // % concluído vs iniciado
  bottleneckSteps: string[]          // steps com maior desvio do estimado
  fastestExecution: { id: string; durationMinutes: number }
  slowestExecution: { id: string; durationMinutes: number }
}
```

## Notas Tecnicas

- **Cálculo server-side**: Métricas devem ser calculadas no API route, não no client (dados podem ser grandes)
- **Paginação**: Usar cursor-based pagination (offset é lento em tabelas grandes)
- **Bottleneck detection**: Step é bottleneck se `avg_duration > estimated * 1.5`
- **Cache**: Métricas podem ter staleTime de 5min (não mudam em tempo real)
- **Empty state**: Mostrar mensagem amigável quando workflow nunca foi executado
