## Descricao

Implementar o modulo de gestao de clientes no painel administrativo. O admin precisa ver todos os perfis cadastrados, buscar por nome/email/CNPJ, filtrar por tier e role, editar dados do perfil, gerenciar enderecos e promover usuarios.

### Schema do Cliente (referencia `database.ts`)
```typescript
interface Profile {
  id: string
  company_name: string | null
  cnpj: string | null
  phone: string | null
  tier: UserTier       // 'bronze' | 'silver' | 'gold'
  role: UserRole       // 'customer' | 'admin' | 'super_admin'
  created_at: string
}

interface UserAddress {
  id: string
  user_id: string
  zip_code: string | null
  street: string | null
  number: string | null
  district: string | null
  city: string | null
  state: string | null
  is_main: boolean
  created_at: string
}
```

### RPC Existente
Ja existe a funcao `get_admin_clients` no Supabase que retorna profiles com email do auth.users (sem expor hash de senha):
```typescript
get_admin_clients: {
  Args: { page?: number; page_size?: number; search_term?: string; filter_tiers?: string[]; filter_roles?: string[] }
  Returns: Array<Profile & { email: string; total_count: number }>
}
```

### Funcionalidades
1. **Listagem** - Tabela paginada usando `get_admin_clients` RPC
2. **Busca** - Por nome, email ou CNPJ (via `search_term`)
3. **Filtros** - Tier (Bronze/Silver/Gold), Role (Customer/Admin/Super Admin)
4. **Modal de Detalhes** - Dados editaveis do perfil
5. **Edicao de Tier** - Mudar tier do cliente (afeta desconto)
6. **Promocao a Admin** - Somente `super_admin` pode promover roles
7. **Gestao de Enderecos** - Ver e gerenciar enderecos do cliente
8. **Badges Visuais** - Tier e role com cores distintas

## Notas Tecnicas

- **RPC `get_admin_clients`**: Essa funcao ja existe no Supabase e retorna profiles com o campo `email` do `auth.users` via join seguro. Ela aceita `page`, `page_size`, `search_term`, `filter_tiers` e `filter_roles`. O `total_count` vem em cada row (padrao Supabase RPC com window function).
- **Chamar RPC no Supabase JS**: `supabase.rpc('get_admin_clients', { page: 1, page_size: 20, search_term: 'busca' })`.
- **Protecao de Role**: No frontend, verificar `profile.role === 'super_admin'` antes de renderizar o select de role. No backend, a RLS policy deve garantir que so super_admin pode alterar o campo `role`.
- **Mascaras**: Exibir CNPJ formatado (`XX.XXX.XXX/XXXX-XX`) e telefone formatado (`(XX) XXXXX-XXXX`). Usar as mesmas funcoes de formato ja existentes em `src/lib/format.ts`.
- **Enderecos**: Buscar enderecos com `supabase.from('user_addresses').select('*').eq('user_id', userId).order('is_main', { ascending: false })`.
- **Set Main Address**: A RPC `set_main_address` faz toggle atomico (desmarca o anterior e marca o novo). Chamar e revalidar lista de enderecos.
- **Email**: Por enquanto, exibir email como somente leitura. A alteracao de email via admin requer RPC adicional (`update_admin_user_email`) que pode ser implementada em fase futura.
