# SOP: Workflow do ClickUp — Agencia Jubileu

## Fluxo de Status (6 etapas)

```
Backlog → A Fazer → Em Progresso → Em Revisao → Aprovado → Concluido
```

| Status | Quando usar | Quem move |
|--------|------------|-----------|
| **Backlog** | Ideia registrada, sem previsao | Qualquer um |
| **A Fazer** | Proxima na fila, pronta para pegar | Fernando/Karol |
| **Em Progresso** | Alguem esta trabalhando agora | Responsavel da tarefa |
| **Em Revisao** | Feito, esperando aprovacao | Responsavel da tarefa |
| **Aprovado** | Aprovado, pronto para publicar/entregar | Aprovador (Fernando/Karol/Cliente) |
| **Concluido** | Entregue e finalizado | Responsavel da tarefa |

## Regras de Uso

### Assignees
- Toda tarefa DEVE ter um responsavel
- Se voce comecou, mova para "Em Progresso"
- Se terminou, mova para "Em Revisao" (nao para Concluido)

### Due Dates
- Toda tarefa DEVE ter prazo
- Start date = quando comeca | Due date = quando entrega

### Checklists
- Marque cada subtarefa ao completar
- Nao mova para "Em Revisao" ate todas as subtarefas estarem marcadas

### Prioridades
- **Urgent** (vermelho): Precisa ser feito HOJE
- **High** (amarelo): Precisa ser feito ESTA SEMANA
- **Normal** (azul): Prazo definido, sem urgencia extra
- **Low** (cinza): Quando der, sem prazo critico

## Niveis de Aprovacao

### Nivel 1: Autonomia Total (Karol + Gabriel decidem)
- Posts de rotina seguindo o DNA da marca
- Agendamento de conteudo ja aprovado
- Respostas a comentarios/DMs padrao

### Nivel 2: Aprovacao Karol
- Artes dentro do guideline
- Edicao de videos curtos de rotina
- Pequenos ajustes de copy

### Nivel 3: Aprovacao Fernando (responder em 24h)
- Novos roteiros de campanha
- Estrategia de trafego pago (budget > R$500)
- Novo posicionamento ou tom de voz
- Propostas para clientes

### Nivel 4: Decisao Conjunta (reuniao semanal)
- Onboarding de novo cliente
- Mudanca de escopo contratual
- Investimentos em ferramentas

## Regra do Timeout

> Se Fernando nao responder uma aprovacao Nivel 3 em **48 horas**, a tarefa e automaticamente aprovada com nota: "Auto-aprovado por timeout."
