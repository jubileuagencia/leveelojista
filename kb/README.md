# Knowledge Base — Agencia Jubileu

Base de conhecimento centralizada da agencia. Todo material aqui serve como fonte de verdade para producao de conteudo, estrategias e operacoes.

## Estrutura

### `/brand-dna/`
DNA de cada marca atendida: tom de voz, identidade visual, valores, guidelines.
- `levee-hortiplus.md` — Hortifruti moderno, delivery Pampulha
- `caracol.md` — Laboratorio de Brincar Criativo
- `pelicula-sideral.md` — Astrologia, entretenimento, Victor Dornelas

### `/personas/`
Mapeamento de personas por cliente: demografico, comportamental, jornada de compra.
- `levee-personas.md`
- `caracol-personas.md`
- `pelicula-personas.md`

### `/sops/`
Standard Operating Procedures — processos padronizados da agencia.
- `criacao-conteudo-ia.md` — Workflow de criacao com IA
- `onboarding-cliente.md` — Processo de entrada de novo cliente
- `producao-video.md` — Pipeline de producao de video
- `gestao-trafego-pago.md` — Gestao de campanhas pagas
- `workflow-clickup.md` — Como usar o ClickUp na agencia

### `/playbooks/`
Playbooks taticos para acoes especificas.
- `lancamento-instagram.md` — Como lancar um novo perfil
- `funil-manychat.md` — Como construir funis no ManyChat

## Como usar

1. **Antes de criar conteudo** → Consulte o brand-dna do cliente
2. **Antes de produzir** → Consulte o SOP relevante
3. **Para novos membros** → Leia o onboarding e os SOPs
4. **Para IA/prompts** → Os prompts em `/prompts/` usam estes docs como contexto

## Atualizacao

- Qualquer membro pode propor mudancas via PR
- Mudancas em brand-dna requerem aprovacao do Fernando
- SOPs sao revisados mensalmente
